# Agentic AI Learning 🚀

This repository contains my hands-on learning and experiments while learning **Agentic AI**.

I’m building things step by step — starting from understanding how LLMs work in an agent setup and gradually moving towards more advanced agentic systems.

## 📚 What's Inside

### 1. Building an AI Agent From Scratch

Understanding the fundamentals of how an AI agent works without relying heavily on agent frameworks.

* LLM interaction
* Tool calling
* Agent loop
* Giving the agent access to external functions
* Understanding how the agent decides what action to take

### 2. Tools with SDKs

Learning how to build agents using an SDK and give them tools they can use.

* Defining tools
* Tool schemas
* Function execution
* Connecting tools with LLMs
* Understanding the agent/tool interaction

### 3. Multi-Agent Systems

Learning how multiple specialized agents can work together.

* Multiple agents
* Agent handoffs
* Agent as a tool
* Routing requests to the right agent
* Building systems such as Sales Agent + Refund Agent

### 🔜 More Coming

This repository will continue to grow as I learn more about Agentic AI.


## 🎯 Goal

The goal of this repository is **learning by building**.

Instead of only learning the theory, I want to understand how agentic systems actually work by implementing them myself and gradually moving from simple agents to more capable AI applications.

---

> **Learn → Build → Experiment → Improve**
